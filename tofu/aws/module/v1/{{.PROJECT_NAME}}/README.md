## Getting started

1. Install [mise](https://mise.jdx.dev) — it manages the whole toolchain
   (opentofu, task, pre-commit, git-cliff, tflint, terraform-docs,
   trivy).
2. Trust and install the pinned toolchain:

   ```sh
   mise trust && mise install
   ```

3. See the available project targets:

   ```sh
   task --list
   ```

```sh
task setup      # install the pre-commit hooks and tflint plugins
task validate   # tofu validate for the module and examples/complete
task lint       # tflint (terraform preset + AWS ruleset)
task scan       # trivy config security scan
task docs       # regenerate the inputs/outputs tables below
```

## Commits and changelog

Commit messages follow [Conventional
Commits](https://www.conventionalcommits.org); the commit-msg hook checks
them. Generate the changelog with:

```sh
task changelog   # git-cliff -o CHANGELOG.md
```

## Layout

- `main.tf` / `variables.tf` / `outputs.tf` / `versions.tf` — the module
- `examples/complete/` — a runnable example, validated by `task validate`
- `Taskfile.yml` — project targets (`task --list` to see them)
- `mise.toml` — pinned toolchain
- `.tflint.hcl` — tflint config (terraform recommended preset + AWS ruleset)
- `.pre-commit-config.yaml` — tofu fmt on commit, commitizen on commit-msg
- `cliff.toml` — git-cliff changelog configuration
